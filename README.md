# ViaLiora UI review demo

[Open the interactive demo](https://jennifer288.github.io/vialiora-demo/)

This repository contains only compiled static website files for UI/UX review.
The application source and backend remain in a separate private repository.

All patient profiles, medical records, reviews, appointments, estimates and journey
plans are fictional. This is not a medical service and does not accept real records,
payments or personal information. There are no deployed medical APIs or admin services.

Hospital concept images and illustrative portraits are demonstration materials,
not verified photographs or claims of hospital affiliation.

- Current patient experience: `/`
- Page index: `/review/`
- Design system: `/design-system/`
- Version comparison: `/compare/`
- Fictional doctor workspace: `/versions/v2/doctor/cases/`

Historical prototypes retain independent demonstration sessions.
The website and its compiled frontend resources are public and require no login.
